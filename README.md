# Физика с Си

Репетитор по физике (ЕГЭ 2028 + олимпиады). Статический сайт: открой `index.html` через любой веб-сервер или GitHub Pages.

- Задачи, уроки и чат генерирует Claude через API Anthropic. Ключ (`sk-ant-…`) вставляется в «Настройках», хранится в `localStorage` и уходит напрямую в `api.anthropic.com`.
- Прогресс хранится в браузере (`localStorage`).
- Олимпиады и правила льгот — в `data.json`.

Локально: `python3 -m http.server` в этой папке, затем http://localhost:8000.
